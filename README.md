# かんたん音楽メーカー（MUSIC MAKER）

音楽の知識がない人でも曲が作れる、ブラウザだけで動くステップシーケンサー。
**選んだキー／スケールの音しかマスに置けない**ので、どこを押しても曲になります。

**▶ https://fumiakim.github.io/music-maker/**

- 開くと **👶 こどもモード**（8マス×5音）から始まります。くわしい編集は「おとなモード」へ。
- 依存なし・ビルド不要（素の HTML + JavaScript + Canvas + Web Audio API）
- 音源ファイルは持たず、**すべてその場で合成**（ドラムもシンセもコードも）
- 開発場所: `~/Desktop/アプリ制作/music-maker/`

### 起動モード

| URL | 開くモード |
|---|---|
| （そのまま） | 前回使ったモード。はじめての人は**こどもモード** |
| `?mode=adult` | おとなモードで開く |
| `?mode=kids` | こどもモードで開く |

## 起動

```bash
python3 -m http.server 8179 --directory ~/Desktop/アプリ制作/music-maker
```

そのあとブラウザで http://localhost:8179 を開く。
（Claude Code からは `.claude/launch.json` の `music-maker` で起動できます）

`file://` で直接開いても動きますが、ローカルサーバー経由を推奨。

## つかいかた（初心者向けの流れ）

1. **🎲 作る** … ジャンルを選んで押すと、ドラム・ベース・コード・メロディが自動でできる。気に入るまで押す。
2. **マスをぬる** … クリックで音を置く／もう一度で消す／ドラッグで連続。`Shift`＋クリックでアクセント。
   となりどうしをつなげると**長い音**になる。
3. **コードを選ぶ** … そのキーで使える7つのコードだけが並ぶ。「進行プリセット」（ポップ王道・カノン進行・小室進行…）を当てはめてもよい。
   メロディ段の**少し明るい行＝いまのコードに合う音**。
4. **パターンA〜Dを並べる** … 各パターン＝1小節。「曲のならび」で A→B→C→D のように並べたものが1曲。
5. **🎧 WAVで書き出し** … 音声ファイルとして保存（OfflineAudioContext でレンダリング）。

キーボード: `スペース`＝再生／停止、`1`〜`4`＝パターン切替、`⌘Z`＝もどす。

## 👶 こどもモード

右上の **👶 こどもモード** で、未就学〜低学年でも遊べる画面に切り替わります。

- **8マス × 5音（ど れ み そ ら ど）＋ ドラム3つ（どん・たん・しゃか）だけ**。文字はひらがな、音は虹色のブロック。
- ベースとコード（ド→ソ→ラm→ファ）は**自動**。子どもはメロディとドラムだけを触る。
- かいたメロディは **A〜D 全パターンに書きこまれる**ので、コードが移り変わりながら同じフレーズがくり返される＝ちゃんと「曲」に聞こえる。
- ボタンは `▶` / 🎲おまかせ / 🧹けす / 🎧ほぞん(WAV) / 楽器4つ(🔔🎹🎸👾) / はやさ3つ(🐢🚶🐇) だけ。
- 5音ペンタトニックなので**どのマスを押しても濁らない**。マスを横につなげると音がのびる。
- こどもモードとおとなモードの曲は **localStorage の別キーに保存**され、行き来しても互いに消えない。
- **初期表示はこどもモード**。切り替えると `musicMaker.mode` に記憶され、次回はそのモードで開く。
  ちらつき防止のため、どちらで開くかは `index.html` の `<head>` 内スクリプトで先に判定して `html.boot-kids` を付けている。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面（HTML + CSS）とヘルプ、こどもモードのオーバーレイ |
| `music.js` | 音楽の知識（スケール／コード／進行プリセット／ジャンル／自動作曲） |
| `audio.js` | 音の合成（楽器・ドラム・エフェクト）、ステップの発音予約、WAV書き出し |
| `app.js` | 画面描画（Canvas）・操作・シーケンサー・保存・モード切替 |
| `kids.js` | こどもモード（8マスの画面と、16ステップへの読み書き変換） |

## 設計メモ

- **1パターン = 1小節 = 16分音符16ステップ**。パターンは A〜D の4つ。コードは1パターンに1つ。
  → A〜Dを並べれば「4小節のコード進行」になる、という割り切り。
- **スケール固定**: メロディ／ベースの縦軸はスケールの音だけ。行ラベルは移動ド（マイナー系はラ始まり）。
  スケールを変えると行数が変わるので `Music.resizeGrids()` で作り直す（重なる範囲は保持）。
- **コード**: 親スケール（メジャー／ナチュラルマイナー）から三和音を組み立て、度数から `C` `Dm` `Bm(♭5)` のような名前を自動生成。
  ペンタトニックなど5音スケールでも、コードは親の7音から作る。
- **音の長さ**: 同じ行で連続したマスを1つの音として扱う（`Music.runLength`）。
  そのため**同じ高さの音を切れ目なく並べることはできない**（自動作曲側でも隣接する同音は避けている）。
- **スケジューリング**: 25ms ごとの `setInterval` で 120ms 先まで予約する定番方式。
  描画は `requestAnimationFrame` で、予約時に積んだキューを `ctx.currentTime` と突き合わせて再生位置を出す。
- **同じ発音コードを再生と書き出しで共用**: `AudioEngine.scheduleStep(ctx, graph, ...)` は
  `AudioContext` でも `OfflineAudioContext` でも動く。書き出しは実時間より速く完了する（8小節で約1.4秒）。
- **音量**: マスター → コンプレッサー → 0.86 の出力ゲイン。全ジャンルでピーク 0.74〜0.85（クリップなし）を確認済み。
- **保存**: 編集のたびに localStorage へ自動保存（おとな `musicMaker.v1` / こども `musicMaker.kids.v1`）。`.json` での保存／読込もあり。
- **こどもモードの実装**: 画面だけを差し替え、曲データは同じ16ステップ形式のまま。
  1マス = 2ステップ（8分音符）、メロディ行 = ペンタの度数5〜10（C5〜C6）、ドラム3行 = `Music.DRUMS` の 0/1/3。
  `app.js` の `enterKids()/exitKids()` が曲と保存キーを差し替え、`window.MM` 経由で `kids.js` がエンジンを借りる。

## 既知の制限

- 1パターン16ステップ固定（3拍子や32分音符は不可）。
- コードはパターンごとに1つ（小節の途中で変えられない）。
- MIDI 書き出しは未対応（WAV のみ）。
- ドラムは1キットのみ（音色切替なし）。
