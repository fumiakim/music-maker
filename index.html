つかいかた

音楽の知識がなくても大丈夫。選んだキーとスケールの音しかマスに置けないので、どこを押しても曲になります。

1. まず「🎲 作る」を押す

ジャンルを選んで おまかせ作曲 を押すと、ドラム・ベース・コード・メロディが自動でできます。気に入るまで何度でも押してください。そこから直していくのがいちばん近道です。

2. マスをぬる

4つの段（メロディ／コード／ベース／ドラム）は、よこが時間（1小節を16こまに分けたもの）、たてが音の高さです。クリックで置く、もう一度クリックで消す、ドラッグで連続してぬれます。となりどうしをつなげると長い音になります。左の「ド・レ・ミ」は移動ド（そのキーでのよび方）です。

3. コードを選ぶ

コードの帯にあるボタンは、そのキーで使ってよい7つのコードだけが並んでいます。パターンごとに1つ選びます。迷ったら「進行プリセット」（ポップ王道・カノン進行など）を当てはめればOK。メロディ段の少し明るい行がそのコードに合う音です。

4. 4つのパターンをつなげて曲にする

パターンA〜Dはそれぞれ1小節。「曲のならび」で A→B→C→D のように並べたものが1曲になります。チップをクリックすると A/B/C/D が切り替わり、＋−で長さを変えられます。

5. 書き出す

🎧 WAVで書き出しで音声ファイルとして保存できます（そのままSNSや動画で使えます）。💾 保存は作りかけのデータ（.json）です。作業内容はブラウザにも自動保存されます。

👶 こどもモードについて

右上の 👶 こどもモード を押すと、8マス×5音（ドレミソラ）とドラム3つだけの画面に切り替わります。 ベースとコード（ド→ソ→ラm→ファ）は自動で鳴りつづけ、かいたメロディは4小節ぶんくり返されるので、 どこを押しても曲になります。読める文字はひらがなだけ、ボタンは「▶ / 🎲おまかせ / 🧹けす / 🎧ほぞん / 楽器4つ / はやさ3つ」だけ。 こどもモードとおとなモードの曲は別々に保存されるので、行き来しても作りかけは消えません。

こまったら

  • 音が出ない → 画面のどこかを一度クリックしてから再生（ブラウザの制限のため）。
  • ごちゃごちゃしてきた → 各段の 🔊 でその段だけ消音して聴き比べる。
  • 雰囲気を変えたい → スケールを「マイナー」や「ペンタ」に変えるだけで別の曲に聞こえます。
